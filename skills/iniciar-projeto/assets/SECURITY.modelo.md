# Política de segurança

## Como reportar uma vulnerabilidade

**Não abra issue pública.** Use um destes canais:

- <GitHub: aba "Security" → "Report a vulnerability" (relato privado de vulnerabilidade)>
- <E-mail: seguranca@exemplo.com.br>

Inclua: o que encontrou, como reproduzir, o impacto que você enxerga e, se quiser, como
prefere ser creditado.

## O que esperar

- Confirmação de recebimento em até <N> dias úteis.
- Avaliação inicial e plano em até <N> dias úteis.
- Aviso quando a correção for publicada.
